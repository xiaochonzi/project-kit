# 支持按标签筛选待办

## 问题与依据

用户无法按标签筛选待办，标签功能形同虚设。

## 目标

支持按标签筛选待办列表，结果即时生效。

## 用户流程

用户在列表页选择标签，列表按标签过滤；清除标签后恢复完整列表。

## 范围

### 包含

标签筛选 UI 与查询逻辑。

### 不包含

标签管理、标签编辑。

## 输入与输出

输入：标签 ID；输出：筛选后的待办列表。

## 业务规则

空标签不触发筛选；无匹配标签时显示空列表。

## 失败与边界情况

无匹配标签 → 空列表提示。

## 验收标准

- 选择标签后列表只显示该标签的待办
- 清除标签后恢复完整列表
- 无匹配标签时显示空列表

## 未决问题

无。
