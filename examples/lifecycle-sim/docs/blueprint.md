# Project Blueprint

## 背景与目标

MyFocus 是一个命令行待办工具,解决终端用户快速记录与管理待办的需求。第一版提供添加、列出、完成与本地持久化。

## 非目标

- 不做提醒/通知功能。
- 不做多用户、云同步。
- 不做 GUI。

## 用户与核心场景

- 场景一:终端用户快速添加一条带优先级和标签的待办。
- 场景二:用户查看待办列表,按优先级决定先做什么。
- 场景三:用户完成一项待办,标记后列表更新。

## 成功标准

- 核心闭环(添加→列出→完成)稳定可用,数据重启不丢。

## 系统能力地图

- 待办管理:添加、列出、完成。
- 数据持久化:todo.json 读写。

## 模块与职责边界

- 命令层(todo.js):CLI 入口、参数解析、输出格式化。
- 数据层(todo-store.js):持久化、校验、排序。

## 核心数据流

add 命令 → 数据层校验并写入 todo.json → list 命令 → 数据层读取并排序 → 输出。

## 外部系统边界

- 无外部服务;仅本地文件系统。

## 数据权威

- todo.json 为唯一数据权威。

## 跨模块约束

- 命令层不得直接读写文件,必须经数据层接口。

## 非功能要求

- 启动快(<100ms),无第三方依赖。

## 风险与假设

- 假设单用户单进程使用,不做并发控制。

## 未决问题

- 无。
