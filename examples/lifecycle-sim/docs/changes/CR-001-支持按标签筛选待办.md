# 支持按标签筛选待办

## 需求来源

用户反馈:M1 已支持标签存储,但 list 无法按标签筛选,标签没有实际用途。

## 当前问题

`node todo.js list` 只支持全量展示,标签只作展示。用户需要 `list --tag home` 只显示 home 标签的待办。

## 期望结果

list 支持 `--tag <标签>` 筛选;空结果输出"该标签下暂无待办"。

## 与现有能力的关系

- 数据层已有 tags 字段(F-M1-01 交付)
- 属于小型增强:单命令参数扩展 + 数据层筛选函数

## 可能影响的模块和文档

- examples/lifecycle-sim/todo-store.js(新增 byTag 筛选)
- examples/lifecycle-sim/todo.js(list 增加 --tag)
- docs/specs/M2/F-M2-01.md(新 Feature)
- docs/requirements.md(新 REQ-006)

## 初步规模

小:2-3 个文件,约 1 个任务可完成。

## 优先级建议

Should。

## 未决问题

无。

## 接入方案与取舍

方案 A(选): list 增加 --tag 参数,数据层新增 byTag 筛选,复用现有 tags 字段。
方案 B(不选): 标签索引与统计 —— 超出本次需求,复杂度高。

## 决定

用户已确认:accepted,进入 M2,作为 F-M2-01。
