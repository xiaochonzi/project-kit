## 原始需求文档

# MyFocus - 命令行待办工具(初始想法)

用户想要一个简单的命令行待办事项工具,解决"手机上用待办 app 太烦,想要终端里快速记录"的问题。

初步设想:
- 可以添加待办事项(标题 + 优先级 + 标签)
- 可以列出待办事项(按优先级排序)
- 可以标记完成
- 数据持久化到本地文件,重启不丢
- 第一版只做 CLI,不做 GUI

用户不确定的:
- 是否要提醒功能(先不做,以后再说)
- 是否需要多用户/同步(明确不做)
- 标签是否支持层级(先做简单标签)
