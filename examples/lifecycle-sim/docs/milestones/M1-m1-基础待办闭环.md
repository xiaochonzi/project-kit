# M1 基础待办闭环

## 阶段目标

用户可以通过 CLI 完成待办的添加、列出、完成,数据持久化到本地文件。

## 可验证系统状态

运行 `node todo.js` 的 add/list/done 命令,待办可被创建、排序展示、标记完成,重启进程后数据仍在。

## 包含

- add/list/done 三个命令
- todo.json 持久化
- 优先级排序与完成状态展示

## 不包含

- 标签筛选与统计
- 提醒功能
- 云同步

## 前置依赖

无。

## Feature Map

F-M1-01 添加与列出待办(无依赖)
F-M1-02 标记完成与持久化(依赖 F-M1-01)

## 退出标准

- 全部 Feature verified
- 核心闭环可用:添加 → 列出 → 完成 → 重启数据不丢

## 风险与假设

单用户单进程使用,不做并发控制。

## 未决问题

无。
