# 按标签筛选待办

## 问题与依据

M1 已支持标签存储但无法筛选,标签无实际用途(CR-001, REQ-006)。

## 目标

list 支持 --tag 参数按标签筛选,提供友好空结果提示。

## 用户流程

`node todo.js list --tag home` → 只显示含 home 标签的待办。

## 范围

### 包含

- todo-store 新增 byTag 筛选函数
- list 命令支持 --tag 参数

### 不包含

- 多标签组合筛选(以后)
- 标签统计

## 输入与输出

- list --tag <标签> → 过滤后的待办列表

## 数据与接口

数据层 byTag(todos, tag) 或 list({tag});复用现有 tags 字段。

## 业务规则

- 标签精确匹配(不区分大小写)
- 无匹配时输出"该标签下暂无待办",退出码 0

## 失败与边界情况

- 空标签参数:等同全量 list
- 标签不存在:友好提示

## 非功能约束

无。

## 验收标准

- AC1: list --tag home 只显示 home 标签待办
- AC2: 无匹配输出"该标签下暂无待办"退出码 0
- AC3: 不传 --tag 时行为与 M1 一致(回归)
