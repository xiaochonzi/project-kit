# 标记完成与持久化

## 问题与依据

用户需要标记待办完成并持久化(REQ-003)。

## 目标

提供 done 命令,完成状态写入 todo.json 并跨重启保持。

## 用户流程

运行 `node todo.js done <id>` → list 中该项显示 [x]。

## 范围

### 包含

- done 命令
- 完成状态持久化

### 不包含

- 撤销完成
- 完成统计

## 输入与输出

- done: `node todo.js done <id>`
- list 中已完成项标记 `[x]`

## 数据与接口

数据层 markDone(id);todo.json 中 done: true。

## 业务规则

- id 不存在报错
- 重复 done 幂等,不报错

## 失败与边界情况

- 非法 id:报错且不修改数据
- todo.json 损坏:拒绝启动并提示

## 非功能约束

无第三方依赖。

## 验收标准

- AC1: done 后 list 显示 [x]
- AC2: 重启后完成状态保持
- AC3: 不存在的 id 报错且数据不变
