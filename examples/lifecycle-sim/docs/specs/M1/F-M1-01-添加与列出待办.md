# 添加与列出待办

## 问题与依据

用户需要快速在终端添加并查看待办(REQ-001/002/004/005)。

## 目标

提供 add/list 命令,数据持久化,空列表友好提示。

## 用户流程

运行 `node todo.js add "买牛奶" --priority high --tags home`,随后 `node todo.js list` 看到排序后的待办。

## 范围

### 包含

- add 命令(标题必填,优先级/标签可选)
- list 命令(按优先级排序,显示完成状态)
- todo.json 读写

### 不包含

- done 命令(属 F-M1-02)
- 标签筛选

## 输入与输出

- add: `node todo.js add <title> [--priority high|medium|low] [--tags a,b]`
- list: `node todo.js list` → 按优先级排序输出

## 数据与接口

数据层接口 load/save/add/list;todo.json 条目格式 {id,title,priority,tags,done,created_at}。

## 业务规则

- 标题为空拒绝
- priority 非法值拒绝(默认 medium)
- list 按 high > medium > low 排序,同优先级按创建时间

## 失败与边界情况

- todo.json 损坏:拒绝启动并提示
- 空列表:输出"暂无待办",退出码 0

## 非功能约束

无第三方依赖;启动 <100ms。

## 验收标准

- AC1: add 后 list 能看到该待办
- AC2: 不同优先级待办按 high > medium > low 排序输出
- AC3: 重启进程后 list 数据仍在(todo.json 持久化)
- AC4: 空数据时 list 输出"暂无待办"且退出码 0
